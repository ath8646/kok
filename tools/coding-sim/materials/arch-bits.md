[컴퓨터구조] 3주차 필기 - 2진수, 비트 연산, 어셈블리

이번 주는 2진수와 16진수 표현, 음수를 저장하는 2의 보수(two's complement), 비트 연산 트릭, 그리고 CPU 성능 계산을 배웠다. 교수님이 시험에 그대로 나온다고 하신 부분에는 ★ 표시를 했다.

1. 16진수와 2의 보수 ★

16진수는 0 부터 9 까지 쓰고, 그 다음은 A(10)부터 F(15)까지 쓴다. 앞에 0x 를 붙이면 16진수라는 뜻이다. `0x1F` 는 1 × 16 + 15 = 31 이고, 2진수로는 11111 이다. 16진수 한 자리는 2진수 4자리와 딱 맞아떨어져서, 1 은 0001, F 는 1111 로 바꿔 붙이면 된다. 그래서 메모리 주소나 기계어를 적을 때 16진수를 많이 쓴다.

컴퓨터는 음수를 2의 보수로 저장한다. n 비트에서 -x 는 x 의 모든 비트를 뒤집고 1 을 더한 값이다. 8비트로 -1 을 쓰면 1111 1111 이고 16진수로는 0xFF 이다. 8비트로 표현할 수 있는 범위는 -2^7 부터 2^7 - 1 까지, 즉 -128 ~ 127 이다. 2의 보수의 장점은 뺄셈 회로를 따로 만들지 않고 덧셈 회로 하나로 처리할 수 있다는 것이다. 그래서 대부분의 CPU 가 이 방식을 쓴다고 하셨다.

```
0x1F = 0001 1111 (2진수) = 31
-1   = 1111 1111 (8비트 2의 보수) = 0xFF
```

2. 비트 연산 트릭 ★

`x & (x - 1)` 은 x 에서 가장 오른쪽에 있는 켜진 비트(1)를 지운다. 그래서 x 가 0 이 아닌데 이 값이 0 이면 x 는 2의 거듭제곱이다. 예를 들어 x = 12 는 1100 이고, x - 1 = 11 은 1011 이다. 둘을 & 하면 1000 이 되어 가장 오른쪽의 1 이 지워진다. 아래 코드는 이것을 함수로 만든 것이다.

```c
int is_pow2(unsigned int x) {
    return x != 0 && (x & (x - 1)) == 0;
}

x = x | (1 << k);   /* k번째 비트만 1로 켠다 */
```

`x | (1 << k)` 에서 1 << k 는 1 을 k 칸 왼쪽으로 민 값, 즉 2^k 이다. 나머지 비트는 그대로 두고 k 번째 비트만 켜진다는 점이 중요하다고 강조하셨다. 플래그를 세우거나 특정 자리만 골라낼 때 이 두 연산을 자주 쓴다.

3. 어셈블리 명령

어셈블리에서는 쉼표 앞이 결과가 들어가는 곳이다. 레지스터는 CPU 안에 있는 아주 작고 빠른 저장 공간이다. mov eax, 1 은 eax 레지스터에 1 을 넣는다.

    mov eax, 1
    add r1, r2, r3

add r1, r2, r3 는 r2 와 r3 을 더해서 r1 에 넣는다. 피연산자가 세 개인 이 형식은 ARM 에서 쓰고, x86 의 add 는 add eax, ebx 처럼 두 개만 쓴다고 하셨다.

4. 불 대수와 정보량

A·B + ¬A 를 정리하면 B + ¬A 가 된다. 진리표로 보면 A 가 0 일 때 두 식 모두 1 이고, A 가 1 일 때 두 식 모두 B 가 되어 같다. 드모르간 법칙 ¬(A·B) = ¬A + ¬B 도 같이 외워 두자. 진리표는 변수가 n 개면 2^n 줄이 필요하니, A 와 B 두 개면 네 줄이면 된다.

n 비트로는 2^n 가지 값을 표현할 수 있다. 예를 들어 32비트 주소는 2^32 바이트, 즉 4GB 까지 가리킬 수 있다. 거꾸로 N 가지를 구분하려면 log_2 N 비트가 필요하다. 예를 들어 1000 개를 구분하려면 log_2 1000 ≈ 9.97 이므로 최소 10 비트가 필요하다.

5. CPU 시간 계산

CPU 시간 = 명령어 수 × CPI × 클럭 주기 로 계산한다. CPI 는 명령어 하나를 실행하는 데 드는 평균 클럭 수이고, 클럭 주기는 클럭 속도의 역수다. 명령어마다 걸리는 클럭이 달라서 CPI 는 평균값으로 잡는다. 세 값 가운데 하나라도 줄이면 CPU 시간이 줄어든다. 예를 들어 같은 명령어 수에서 CPI 를 1.5 에서 1.0 으로 줄이면 CPU 시간은 0.5 초가 된다.

    명령어 10^9 개, CPI 1.5, 클럭 2GHz 이면
    클럭 주기 = 1 / (2 × 10^9) = 0.5 ns
    CPU 시간 = 10^9 × 1.5 × 0.5 ns = 0.75 초
