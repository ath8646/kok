[알고리즘] 2주차 강의 정리 - 빅오 표기법과 점화식

1. 빅오(Big-O) 표기법
시간 복잡도는 입력 크기 n 이 아주 커질 때 실행 시간이 얼마나 늘어나는지로 본다. 그래서 상수 배와 낮은 차수 항은 버린다. 3n^2 + 5n + 7 의 빅오는 O(n^2) 이다. 정의는 이렇다. 어떤 상수 c 와 n0 가 있어서 n >= n0 인 모든 n 에 대해 f(n) <= c*g(n) 이면 f(n) = O(g(n)) 이라고 쓴다.

- 상수 배는 무시한다: 2n 과 100n 은 둘 다 O(n)
- 가장 큰 항만 남긴다: n^2 + 1000n 은 O(n^2)
- 빅오는 상한이다. 하한은 Omega, 상한과 하한이 같으면 Theta 로 쓴다.

※ 시험에 자주 나온다: "O(n) 이면 Theta(n) 이다"는 틀린 말이다. f(n) = 1 도 O(n) 에 속하기 때문이다.

2. 자주 나오는 증가율 순서
O(1) < O(log n) < O(n) < O(n log n) < O(n^2) < O(2^n)
오른쪽으로 갈수록 n 이 커질 때 훨씬 느려진다. 지수에 n 이 들어가면 상수 배가 아니다. 2^(2n) 은 4^n 이라서 O(2^n) 이 아니다. 이 함정이 시험에 자주 나온다.

3. 로그의 밑과 등차수열의 합
log_2 n, log_10 n, ln n 은 밑만 다르다. 밑을 바꾸는 공식은 log_a n = log_b n / log_b a 이다. log_b a 는 상수라서 빅오에서는 밑을 무시하고 O(log n) 이라고 쓴다.
1 + 2 + … + n = n(n+1)/2 는 꼭 외워 두자. 이중 for 문의 안쪽 반복 횟수를 합으로 계산할 때 계속 나온다.

4. 중첩 반복문 분석
```python
def count_pairs(n):
    cnt = 0
    for i in range(n):
        for j in range(i):
            cnt += 1
    return cnt
```
바깥 루프는 n 번 돈다. 안쪽 루프는 i 에 따라 i 번 도니까 전체 횟수는 0 + 1 + … + (n-1) = n(n-1)/2 이다. 그래서 O(n^2) 이다. 안쪽 루프의 범위가 `range(i)` 처럼 바깥 변수에 묶여 있으면 그냥 곱하면 안 되고 합을 구해야 한다.

이번에는 C 로 같은 구조를 본다.

    int sum = 0;
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= i; j++)
            sum++;

sum++ 은 1 + 2 + … + n = n(n+1)/2 번 실행된다. 안쪽 루프가 1 부터 i 까지 돌아서 역시 O(n^2) 이다.

5. 로그 시간이 나오는 경우
while (i < n) i *= 2; 는 i 가 1, 2, 4, 8 … 로 두 배씩 커진다. 2^k >= n 이 되면 멈추므로 반복 횟수 k 는 대략 log_2 n 이다. 따라서 O(log n) 이다. 같은 자리에서 `i++` 로 바꾸면 n 번 돌아서 O(n) 이 되니 주의하자.

이진 탐색 코드도 같은 이유로 로그 시간이다. `lo` 와 `hi` 는 찾는 범위의 양 끝이다.

```python
def binary_search(a, target):
    lo, hi = 0, len(a) - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if a[mid] == target:
            return mid
        elif a[mid] < target:
            lo = mid + 1
        else:
            hi = mid - 1
    return -1
```

이진 탐색은 비교할 때마다 구간이 절반으로 줄어든다. n -> n/2 -> n/4 -> ... -> 1 이 될 때까지 log_2 n 번쯤 비교하므로 최악은 O(log n) 이다. `mid = (lo + hi) // 2` 에서 고른 가운데 원소가 바로 답이면 한 번에 끝나니 최선은 O(1) 이다. 정렬되지 않은 배열에서는 쓸 수 없다.

6. 점화식
재귀로 짠 알고리즘은 점화식으로 시간을 적는다. 병합 정렬은 T(n) = 2T(n/2) + n 이다. 절반짜리 문제를 두 번 풀고, 합치는 데 n 이 든다는 뜻이다.

(1) 전개로 풀기
T(n) = 2T(n/2) + n = 4T(n/4) + 2n = ... = 2^k T(n/2^k) + k*n
n = 2^k 로 두면 T(n) = n*T(1) + n log_2 n 이므로 T(n) = O(n log n) 이다.

(2) 마스터 정리
T(n) = aT(n/b) + f(n) (a >= 1, b > 1) 에서 c = log_b a 를 구하고 f(n) 과 n^c 의 크기를 비교한다.
- f(n) 이 n^c 보다 다항식으로 작으면: T(n) = Theta(n^c)
- 둘이 같은 차수이면: T(n) = Theta(n^c log n)
- f(n) 이 n^c 보다 다항식으로 크면: T(n) = Theta(f(n)). 단, a*f(n/b) <= k*f(n) (k < 1) 조건이 있어야 한다.

예제
- T(n) = 2T(n/2) + n: a=2, b=2, c = log_2 2 = 1, f(n) = n 은 같은 차수라서 Theta(n log n)
- T(n) = T(n/2) + 1 (이진 탐색): c = 0, f(n) = 1 이라서 Theta(log n)
- T(n) = 4T(n/2) + n: c = 2, f(n) = n 이 더 작아서 Theta(n^2)
- T(n) = 3T(n/2) + n^2: c = log_2 3 = 약 1.585, f(n) = n^2 이 더 커서 Theta(n^2)

※ 시험 포인트: 마스터 정리는 T(n) = aT(n/b) + f(n) 꼴에서만 쓴다. T(n) = T(n-1) + 1 처럼 n/b 가 아닌 꼴이면 전개로 풀어야 한다. 세 경우 중 어디인지 먼저 f(n) 과 n^c 를 비교해서 적어 두면 실수가 줄어든다.
