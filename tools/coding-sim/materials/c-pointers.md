[시스템프로그래밍] 5주차 강의 정리 - 포인터와 메모리

1. 포인터란?
포인터는 메모리 주소를 값으로 가지는 변수다. 주소 연산자 &를 붙이면 변수의 주소를 얻고, 간접 참조 연산자 *를 붙이면 그 주소에 들어 있는 값을 읽거나 바꿀 수 있다. 포인터 변수의 크기는 자료형과 상관없이 CPU 비트 수에 따라 보통 4바이트 또는 8바이트다.

    int x = 10;
    int *p = &x;    // p 에는 x 의 주소가 들어간다
    *p = 20;        // 이제 x 는 20

선언할 때의 *는 "포인터 변수를 만든다"는 뜻이고, 식 안의 *는 "주소가 가리키는 곳을 본다"는 뜻이다. 같은 기호라도 자리에 따라 뜻이 달라서 시험에 자주 나온다.

2. 기본 예제 (main 의 인자)
```c
#include <stdio.h>

int main(int argc, char **argv) {
    int x = 10;
    int *p = &x;
    printf("%d\n", *p);
    return 0;
}
```
argc 는 인자의 개수, argv 는 문자열 포인터들의 배열이다. `argv[0]` 에는 실행 파일 이름이 들어간다. return 0 은 정상 종료를 뜻한다.

3. 동적 메모리 할당
배열 크기를 실행 중에 정해야 하면 malloc 을 쓴다. 반환값은 `void *` 라서 형 변환 없이 받을 수 있지만, 메모리가 부족하면 `NULL` 을 돌려주므로 꼭 확인해야 한다. 핵심은 자료형 크기에 개수를 곱해 주는 것이다. sizeof(int) 만 쓰면 한 칸짜리 메모리가 된다.

    int n = 5;
    int *p = malloc(sizeof(int) * n);
    if (p == NULL) return 1;
    ...
    free(p);    // 다 쓴 뒤 반드시 해제. 해제한 뒤에는 p = NULL 로 두는 습관을 들이자.

free 하지 않으면 메모리 누수가 생기고, free 한 뒤에 그 포인터로 접근하면 허상 포인터(dangling pointer) 문제가 된다.

4. 구조체 포인터와 연결 리스트
연결 리스트는 각 노드가 다음 노드의 주소를 next 에 들고 있는 구조다. 마지막 노드의 next 는 NULL 이다. 구조체 포인터로 멤버에 접근할 때는 `->`를 쓴다. p->next 는 (*p).next 와 같은 뜻이다.

```c
struct Node {
    int data;
    struct Node *next;
};

struct Node *cur = head;
while (cur != NULL) {
    printf("%d\n", cur->data);
    cur = cur->next;
}
```

5. 배열과 포인터
배열 이름 a 는 첫 원소의 주소다. a[i] 는 *(a + i) 와 같은 값을 갖는다. 포인터 덧셈은 바이트가 아니라 원소 크기 단위로 움직인다는 점을 꼭 기억하자. 그래서 a + 1 은 주소가 4바이트(int 기준) 뒤로 간다.

6. 비트 연산자와 논리 연산자
비트 연산: x ^ y (같은 자리의 비트가 다르면 1), x << 2 (왼쪽으로 2칸 이동, 4를 곱한 것과 같음), ~x (모든 비트를 뒤집음)
논리 연산: &&와 || 는 왼쪽만 보고 결과가 정해지면 오른쪽은 계산하지 않는다(단축 평가). !flag 는 flag 가 0일 때만 1이다. !!x 는 x 가 0이 아니면 1, 0이면 0이 되는 관용구다.

※ 시험 포인트: a[i] 와 *(a + i) 가 같은 이유, malloc 뒤 free 누락, !!x 의 용도, x << 2 와 x >> 1 의 의미
