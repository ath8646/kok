자료구조 3주차 정리: 선형 자료구조

■ 1. 스택 (Stack)
- 한쪽 끝에서만 넣고 뺀다. 나중에 들어간 것이 먼저 나온다 → LIFO
- 맨 위를 가리키는 변수 top 을 둔다. 빈 스택이면 top = -1 로 시작
- 주요 연산: push(삽입), pop(삭제), peek(맨 위 확인)

배열로 구현하면 이렇게 된다.

    #define MAX 100
    int stack[MAX];
    int top = -1;

    void push(int x) {
        stack[++top] = x;      // 먼저 top 을 올리고 넣는다
    }

    int pop(void) {
        return stack[top--];   // 꺼낸 뒤에 top 을 내린다
    }

예) push(3), push(5), pop() 을 하면 5 가 나오고 스택에는 3 만 남는다.
- 오버플로: top 이 MAX - 1 인데 push 하면 넘친다. 언더플로: 빈 스택에서 pop 하면 안 된다.
- push, pop 은 모두 O(1). 원소가 몇 개든 한 번에 끝난다.
- 쓰임: 함수 호출 기록(콜 스택), 실행 취소(undo)
- 괄호 검사 예: ( 를 만나면 push, ) 를 만나면 pop 해서 짝이 맞는지 본다.

■ 2. 큐 (Queue)
- 한쪽(rear)에서 넣고 반대쪽(front)에서 뺀다. 먼저 들어온 것이 먼저 나온다 → FIFO
- 선형 배열 큐는 앞쪽 빈칸을 다시 쓸 수 없어서 낭비가 생긴다. 그래서 원형 큐를 쓴다.

```
rear = (rear + 1) % MAX;
queue[rear] = x;
```

- MAX 가 5 일 때 rear 가 4 에서 다음 칸으로 가면 (4 + 1) % 5 = 0 이 되어 맨 앞으로 돌아간다.
- 가득 찬 조건: (rear + 1) % MAX == front
- 빈 조건: front == rear
- 삽입, 삭제 모두 O(1)
- 쓰임: 프로세스 스케줄링, 너비 우선 탐색(BFS)

■ 3. 연결 리스트 (Linked List)
- 자료를 연속된 칸에 두지 않는다. 노드마다 다음 노드의 주소를 가진다.
- C 에서 노드는 이렇게 정의한다.

struct Node { int data; struct Node *next; };

- C 에서는 malloc 으로 노드를 힙에 만들고, 다 쓰면 free 로 돌려준다.
- 노드 하나는 보통 16바이트다 (64비트 환경에서 int 뒤에 맞춤 정렬 패딩이 들어가기 때문).
- 파이썬으로 쓰면 다음과 같다.

    node = Node(10)
    node.next = None    # 마지막 노드는 None 을 가리킨다

- 중간에 넣을 때는 새 노드의 next 를 먼저 연결하고, 앞 노드의 next 를 바꾼다. 순서를 거꾸로 하면 뒤쪽 노드를 잃어버린다.
- 맨 앞 삽입·삭제: O(1)
- 값으로 찾기: O(n). 처음부터 하나씩 따라가야 한다.

■ 4. 배열과 연결 리스트 비교
- 임의 접근: 배열 O(1), 리스트 O(n)
- 중간 삽입: 배열은 원소를 밀어야 해서 O(n), 리스트는 위치를 알면 O(1)
- 메모리: 배열은 연속된 칸, 리스트는 next 칸만큼 더 쓴다.

※ 시험 포인트: 스택은 LIFO, 큐는 FIFO. 원형 큐 조건식은 꼭 외우기!
※ 스택 연산 순서 주의: `stack[++top]` 은 올린 뒤에 쓰고, `stack[top--]` 은 쓴 뒤에 내린다.
