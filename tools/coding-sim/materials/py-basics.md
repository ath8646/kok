[컴퓨터프로그래밍] 3주차 강의자료 - 파이썬 기초 문법

오늘은 파이썬의 산술 연산자, 출력 방법, 슬라이싱을 배웠다. 교수님이 시험에 나온다고 강조하신 부분 위주로 정리.

1. 산술 연산자

파이썬에서는 사칙연산 말고도 몫, 나머지, 거듭제곱을 구하는 연산자가 있다. 가장 많이 헷갈리는 부분이다.

- / : 나눗셈. 결과가 항상 실수(float)로 나온다. 예) 7 / 2 는 3.5
- // : 몫. 소수점 아래를 버린다. 예) 7 // 2 는 3
- % : 나머지. 짝수인지 홀수인지 판별할 때 자주 쓴다.
- ** : 거듭제곱. 2 ** 10 은 1024 이다. 수학에서 쓰는 ^ 기호가 아니니 주의 (^ 는 파이썬에서 비트 XOR 연산이다)

교수님이 특히 강조하신 것: 음수에서 // 는 0 쪽으로 자르는 게 아니라 더 작은 쪽으로 내림한다. 그래서 -7 // 2 는 -3 이 아니라 -4 이다.

```python
a = 7                # 피연산자 1
b = 2                # 피연산자 2
print(a / b)         # 3.5
print(a // b)        # 3, 몫
print(a % b)         # 1, 나머지
print(2 ** 10)       # 1024
print(-7 // 2)       # -4
```

2. print 와 구분 기호

print 함수는 값을 여러 개 넣으면 기본으로 공백을 한 칸 두고 이어서 출력한다. sep 옵션으로 구분 기호를 바꿀 수 있다.

    items = ["사과", "배", "포도"]
    print(*items, sep=", ")
    # 출력: 사과, 배, 포도

별표(*)를 앞에 붙이면 리스트 안의 원소를 하나씩 풀어서 넘겨준다는 뜻이다. 처음 보는 문법이라 필기 옆에 따로 적어 둠.

3. f-string 과 이스케이프 문자

문자열 안에 변수 값을 넣을 때는 따옴표 앞에 f 를 붙이고 중괄호 {} 안에 변수를 쓴다. 소수 자릿수는 {score:.1f} 처럼 콜론 뒤에 적는다.

    name = "민수"
    score = 91.456
    print(f"{name}님 {score:.1f}점")
    # 출력: 민수님 91.5점
    print("이름\t점수\n민수\t91")

\n 은 줄바꿈, \t 는 탭이다. 역슬래시 뒤의 글자 하나가 특별한 뜻을 갖는다고 이해하면 된다.

4. 슬라이싱과 이름 짓기

문자열이나 리스트의 일부를 꺼내는 것을 슬라이싱이라고 한다. a[시작:끝] 에서 끝 번호는 포함되지 않는다. a[::-1] 처럼 간격을 -1 로 주면 거꾸로 된 결과가 나온다.

```python
word = "python"
print(word[1:4])     # yth
print(word[::-1])    # nohtyp

max_value = 100      # 밑줄을 쓴 이름 (snake_case)
x_1 = 3

def main():
    print(max_value ** x_1)   # 1000000

if __name__ == "__main__":
    main()
```

변수 이름은 x_1, max_value 처럼 소문자와 밑줄로 짓는 것이 파이썬 관례다. 공백이나 하이픈은 쓸 수 없다.

파일을 직접 실행했을 때만 main 을 호출하는 부분은 `if __name__ == "__main__":` 이라고 쓴다. 이 부분은 다음 주 함수 단원에서 다시 한다고 하셨다.

샵(#)으로 시작하는 줄은 주석이라서 실행되지 않는다. 설명용으로만 쓴다.
